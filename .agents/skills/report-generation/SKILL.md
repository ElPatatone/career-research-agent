# Report generation

Use reconciled assessed IDs, verified routes with timestamps, candidate evidence, omission entries, source observations and tracker read-back results.

1. Begin with up to three actionable applications selected across new and rechecked roles. Require current-run evidence of open external intake, sufficient candidate context, resolved essential eligibility and a concrete next action. Give company, role, route, one truthful experience angle and material trade-offs or decisions. If none qualify, state explicitly that there are no actionable priorities.
2. Account for all distinct new suitable roles, including promising follow-ups. Report existing rechecks and meaningful changes separately. Give unresolved questions, owners, next actions and dates. List companies worth following and hard exclusions with reasons, even if a section is empty.
3. Ask verbatim, “Were there more roles matching these responsibilities that I found but did not include in the main recommendations?” Answer yes or no for the assessed set. For each omission give identity, evidence, reason, next action and disposition. The main recommendations encompass recommended roles beyond the opening three. Include responsibility matches excluded for closure or essential constraints in the omission review as well as exclusions, counting each ID once. Qualify a partial answer to the known records and explain any accounting gaps.
4. Summarise search coverage, including sources and companies attempted, portfolio fallback, failures and limits. Attribute distinct new assessments to the actual primary discovery source where known. Identify secondary sightings, unattributed records and rechecks separately. Distinguish visits, indexed hits, leads, assessments and actionable results. Record distinct actionable IDs beyond the highlights, duplicate sightings and elapsed time or resource use where measured so later reports can be compared.
5. Give context and tracker access status, recheck and distinct new assessment counts, suitable, follow-up and exclusion totals with their denominators, failures and confirmed persistence. Suitable and follow-up can overlap. Distinguish measured zero from unknown. Record unresolved issues and identify partial execution explicitly.

Check totals against IDs and source evidence before saving the private report. Report a delivery or persistence failure even if the analysis succeeded.
